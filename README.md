# hand-ai

Rust-native tools​ for building AI agents and managing LLM deployments.

## Packages

| Package                                                     | Description                                                      |
| ----------------------------------------------------------- | ---------------------------------------------------------------- |
| **[@wanggang316/hand-model](packages/model)**               | Unified multi-provider LLM API (OpenAI, Anthropic, Google, etc.) |
| **[@wanggang316/hand-agent](packages/agent)**               | Agent runtime with tool calling and state management             |
| **[@wanggang316/hand-coding-agent](packages/coding-agent)** | Interactive coding agent CLI                                     |
| **[@wanggang316/hand-tui](packages/tui)**                   | Terminal UI library with differential rendering                  |
| **[@wanggang316/hand-web-ui](packages/web-ui)**             | Web components for AI chat interfaces                            |
